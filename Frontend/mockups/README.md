Maquette du tableau de bord "Chef projet"

Fichiers:
- chef-projet-dashboard.svg — maquette vectorielle (1440×900)

Exporter en PNG (exemples):

Avec Inkscape (si installé):
```bash
inkscape Frontend/mockups/chef-projet-dashboard.svg --export-type=png --export-filename=Frontend/mockups/chef-projet-dashboard.png --export-width=1440
```

Avec rsvg-convert (librsvg):
```bash
rsvg-convert -w 1440 -h 900 -o Frontend/mockups/chef-projet-dashboard.png Frontend/mockups/chef-projet-dashboard.svg
```

Avec ImageMagick (convert):
```bash
convert Frontend/mockups/chef-projet-dashboard.svg Frontend/mockups/chef-projet-dashboard.png
```

Ouvrir dans le navigateur: glisser-déposer le fichier SVG dans un onglet pour prévisualiser et faire "Enregistrer sous..." ou utiliser un outil d'export.
